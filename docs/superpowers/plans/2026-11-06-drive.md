# Drive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un drive privado por usuario del admin (carpetas, subcarpetas, archivos) cuyos archivos se adjuntan a varios posts y se ven en el blog.

**Architecture:** Laravel: tablas `folders`, `files` y la puente morph `fileables`; Policies que el Admin no salta (interfaz `OwnedPrivately`), FormRequests, Actions en `app/Actions/Drive`, API Resources y un controlador que sirve los archivos del disco privado. Vue: store Pinia `useDriveStore`, componente `DriveBrowser` (página del admin y selector en el editor) y la sección de adjuntos en el post público.

**Tech Stack:** Laravel 12, Sanctum (SPA), spatie/permission, spatie/activitylog, PHPUnit (clases, como el resto de `tests/Feature`); Vue 3 + TS, Pinia, Element Plus (admin), Vuetify (blog), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-06-drive-design.md`

## Global Constraints

- Backend en `/home/daniel/www/awesomeApp`; front en `/home/daniel/www/vue-project`.
- Disco `local` (privado); ruta `drive/{user_id}/{hashName}`.
- Máximo por archivo: `max:20480` (20 MB). Un archivo por petición. Limitador `drive`: 60/min.
- Extensiones bloqueadas: `php, phtml, phar, php3, php4, php5, php7, php8, exe, msi, bat, cmd, sh, com, scr, jar, htaccess`.
- `kind` ∈ `image, video, audio, pdf, document, archive, other`.
- Archivos/carpetas ajenos → **404** (también para un Admin).
- "Post publicado" = `Post::scopeVisible` (status `published`, `published_at` ≤ ahora, no borrado).
- Sin morph map: `fileable_type` = `App\Models\Post`.
- Textos de la interfaz en español. Comentarios en español, como el resto del código.
- Nunca correr seeders. Archivos CRLF (`src/router/index.ts`, `src/main.ts`) se editan preservando `\r\n`.
- Iconos nuevos: MDI en `src/plugins/icons.ts`, Element en `src/layouts/Admin/element-icons.ts`.
- Commits con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; sin `.claude/`; sin push.

## Review Focus

1. **Mismo archivo subido dos veces** → se guardan los dos con `name` distinto; la segunda respuesta trae `duplicate_of` con el id del primero. (Task 3)
2. **Nombre con acentos, espacios y comillas** (`Informe año "final".pdf`) → la descarga conserva el nombre (`Content-Disposition` con `filename*=utf-8''…`). (Task 4)
3. **Renombrar sin escribir la extensión** (`foto.jpg` → `vacaciones`) → queda `vacaciones.jpg`. (Task 3)
4. **Archivo disfrazado** (`foto.jpg` cuyo contenido es `<?php …`) → mime detectado no es imagen, `kind` = `other`, se sirve como `attachment`. (Task 3 y 4)
5. **Post que deja de estar publicado** (vuelve a borrador o se manda a la papelera) → su archivo vuelve a dar 404 a invitados. (Task 4)
